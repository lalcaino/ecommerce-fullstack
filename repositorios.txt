=== SmartLogix — Repositorios GitHub ===

REPOSITORIO PRINCIPAL
─────────────────────
URL: https://github.com/TU_USUARIO/smartlogix
Descripción: Repositorio principal del proyecto SmartLogix. Contiene la documentación
general, el plan de branching y referencias a todos los submódulos.

COMPONENTES
───────────
1. Frontend (React + Vite)
   URL: https://github.com/TU_USUARIO/smartlogix-frontend
   Descripción: Interfaz de usuario empaquetada como módulo NPM. Implementa los
   patrones Repository (api.js), Circuit Breaker y Factory Method. Incluye
   pruebas unitarias con Vitest (cobertura >= 60%).

2. BFF — Backend For Frontend (Django REST Framework)
   URL: https://github.com/TU_USUARIO/smartlogix-bff
   Descripción: Componente orquestador que actúa como API Gateway. Centraliza
   la comunicación entre el frontend y los microservicios. Implementa Circuit
   Breaker por cada microservicio y agrega datos para el Dashboard.
   Puerto: 8000

3. Microservicio de Inventario (Django)
   URL: https://github.com/TU_USUARIO/smartlogix-ms-inventario
   Descripción: Microservicio independiente para gestión de productos y stock.
   Implementa el patrón Repository (ProductoRepository). Puerto: 8001

4. Microservicio de Pedidos (Django)
   URL: https://github.com/TU_USUARIO/smartlogix-ms-pedidos
   Descripción: Microservicio independiente para el ciclo de vida de pedidos.
   Implementa Repository Pattern y Factory Method (PedidoFactory). Puerto: 8002

ESTRATEGIA DE BRANCHING (Git Flow)
───────────────────────────────────
- main         → código estable/producción (protegido, requiere PR)
- develop       → integración continua del equipo
- feature/*     → nuevas funcionalidades (ej: feature/ms-inventario)
- hotfix/*      → correcciones urgentes en producción
- release/*     → preparación de versiones (ej: release/1.0.0)
